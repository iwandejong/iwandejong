Hey! I'm Iwan, an intern at Momentum Life Insurance. My day-to-day work mainly consists of framing, experimenting, and integrating Artificial Intelligence use cases into existing and new systems inside the life insurance domain.

On the side I build projects for fun. I recently built [i](https://github.com/iwandejong/i), an open source fuzzy and recursive `cd` replacement.

I'm currently building an open source headless workflow engine for typed decisions [here](https://github.com/milfordai) for deterministic workflows both on the edge (e.g., home automation) and in enterprise applications.
